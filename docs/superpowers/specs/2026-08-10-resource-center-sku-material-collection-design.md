# 图片任务资源中心弹窗设计

> 日期：2026-08-10  
> 状态：产品方案已确认，第二轮效果图待确认  
> 范围：图片任务内资源中心弹窗与商品组合，不包含业务代码、数据库迁移和 ERP 接口实施

## 1. 目标

在现有 `AssetTransitModal`、公共/个人素材和商品绑定能力上做最小调整，为图片任务增加按 SKU 找产品素材的能力。商品素材库继续作为独立管理页面，资源中心只负责在创作过程中选择和上传素材。

## 2. 已确认原则

1. 一条普通资源只保存一个 `productId`，不建立资源与产品多对多关系。
2. 商品素材库和资源中心不合并；本轮不修改商品素材库页面职责。
3. 资源中心是图片任务内的宽版弹窗，不新增独立导航页面。
4. 弹窗一级入口只有“产品素材、公共素材、我的素材”。
5. 模特资源库保持独立；创作页可以引用，但资源中心不复制模特档案。
6. 上传素材时只选择一个 SKU，不要求分类、标签或 AI 打标确认；资源中心可使用既有分类和已沉淀标签筛选。
7. 产品分类统一使用 ERP 分类；参考图角色只在创作页参考图区域维护，保存后再次引用自动带出。
8. 九大风格及联动场景继续以字典管理为唯一来源，资源中心只读取筛选，不维护第二份字典。
9. 商品组合在产品素材内完成源图选择，确认后带回现有图片任务流程；组合采用单一资源归属，其他参与 SKU 通过组合关系回查。

## 3. 弹窗结构

### 3.1 一级入口

| 入口 | 默认 | 内容 |
| --- | --- | --- |
| 产品素材 | 是 | 按 SKU 查找和上传产品素材 |
| 公共素材 | 否 | 现有公共资源 |
| 我的素材 | 否 | 当前用户上传或生成的个人资源 |

公共素材和我的素材是同一资源数据的不同查询视图，不复制文件。模特资源库不进入这三个入口。

### 3.2 打开规则

1. 图片任务已有 SKU 上下文时，打开资源中心直接显示当前 SKU 素材网格；当前主体图来自 ERP 同步图或用户最近一次更换结果，并在网格中高亮。
2. 弹窗不额外制造默认选择。主体图入口已有值时映射为选中，参考图新增入口没有值时保持零选择并正常展示素材列表。
3. 当前 SKU 标题区展示 ERP 商品名称、SKU/SPU 编码和分类，并提供“切换产品”和“上传素材”。
4. 点击“切换产品”，弹窗内部切换到 SKU 产品列表，不离开图片任务。
5. 图片任务没有 SKU 上下文时，首次打开直接显示 SKU 产品列表。
6. 关闭弹窗后返回原图片任务，商品、Prompt 和已选参考图状态不丢失。

主体图入口继续按现有 `multiSelect=false` 单选；参考图入口按调用参数支持多选。弹窗只负责返回素材，不在内部编辑参考角色。

### 3.3 SKU 产品列表

- 一张卡片对应一个 SKU。
- 同一 SPU 下的 SKU 连续排列，显示轻量 SPU 分组标题。
- 不增加“先进入 SPU 再展开 SKU”的操作层级。
- 单规格商品直接显示一张 SKU 卡片。
- 默认按最近活动时间排序；无本地素材的 SKU 仍可出现，以便上传首批素材。
- 支持 ERP 商品名称、SPU 编码和 SKU 编码搜索。
- 左侧使用 ERP 分类树筛选，至少覆盖睡衣、围巾、帽子、鞋履等实际业务分类，并显示各分类结果数量。

SKU 卡片展示：

- 最近一条素材缩略图；不存在时回退 ERP 商品图。
- ERP 商品名称。
- SKU 编码和规格。
- 素材数量。
- 最近更新时间。

### 3.4 当前 SKU 素材

选择 SKU 后，弹窗显示该 SKU 的素材网格，默认最新优先。素材卡片复用现有预览、选择和上传能力，不增加复杂的详情管理和批量管理。

素材网格支持两组筛选：

- 来源/类型：ERP 同步、用户上传、生成结果、组合结果。
- 已有标签：模特、风格、场景、姿势、细节，以及九大风格和对应联动场景的具体值。

标签来自创作页参考图角色和字典参数，不在资源中心新增打标入口。没有标签的素材仍可按来源、名称和时间检索。

### 3.5 公共素材与我的素材

两个入口必须有独立可见的 HTML 状态，不只保留空标签页：

- 公共素材：使用现有资源分类，展示公共场景、风格、姿势、细节和道具素材；支持分类、标签和搜索。
- 我的素材：展示当前用户上传、生成和收藏的素材；支持来源、标签和搜索，并保留上传入口。
- 两者复用素材卡片、预览和单选/多选行为，但查询范围严格按真实权限隔离。
- 模特档案继续在独立模特资源库管理，资源中心不复制模特档案管理能力。

## 4. 上传与归集

### 4.1 上传

1. 当前 SKU 素材视图上传时，当前 SKU 自动选中。
2. SKU 产品列表上传时，先单选一个 SKU。
3. 上传完成后，资源直接写入当前唯一 `productId`。
4. 不显示入库确认、素材分类、AI 打标或业务标签表单。

### 4.2 归集

图片、视频和组合结果根据任务 `productId` 归属对应 SKU。资源中心按该 `productId` 查询，不要求用户重新维护产品关系。

## 5. 参考图角色与筛选标签

资源中心不提供标签管理，但可以读取已保存标签作为筛选条件。图片确认返回创作页后，用户可以在参考图区域为其多选固定角色：

- 模特
- 风格
- 场景
- 姿势
- 细节

角色保存到素材元数据，再次引用图片时自动带出。当前任务 Prompt 读取这些角色；风格、场景或姿势已由参考图承担时，Prompt 底部对应参数禁用并显示图片来源。

参考图角色表达图片承担的参考维度；具体风格、场景和姿势值继续引用字典管理中的九大风格及其联动规则，不复制枚举。

## 6. 商品组合

### 6.1 创建

- 产品素材顶部提供“单图选择 / 组合素材”模式切换，组合不再缺失入口。
- 进入组合素材后，当前任务商品及其现有主体图按 ERP 分类推断为上装或下装，并允许用户更换角色。
- 当前 SKU 是组合结果的归属 SKU。
- 至少选择两个不同 SKU，角色为上装、下装和可选鞋履。
- 每个角色选择一张有效源图。
- 底部组合栏持续显示上装、下装、鞋履三个槽位和缺失状态。
- 点击“带入图片任务”只回填组合源图和 SKU 关系，复用现有图片任务提交、生成和结果展示流程，不在弹窗内直接创建任务。

### 6.2 保存与展示

- 组合结果资源只保存一个 `productId`，指向当前归属 SKU。
- 组合项目单独保存参与 SKU、角色和源图快照。
- 其他参与 SKU 通过“关联组合”查询到同一项目和同一结果资源。
- 不复制结果、不重复计算成本和审核数量。
- 关联组合不自动成为参与 SKU 后续任务的参考素材。

### 6.3 历史状态

ERP 改名、换图或停用不改写组合历史快照。任一参与 SKU 停用后，组合进入历史状态，保留查看和继续创作能力，但默认不进入新的组合选择器。

## 7. 数据与接口影响

普通资源继续使用单个 `productId`。第一阶段不新增复杂标签表，参考角色可以复用受控的 `tags` 字段，但必须补充统一更新素材元数据的能力。

正式开发前至少确认：

1. 资源中心产品列表返回 SKU、SPU 分组信息、最近素材封面、素材数和最近活动时间。
2. 按 `productId` 查询当前 SKU 素材。
3. 上传和生成结果统一写入唯一 `productId`。
4. 更新参考图角色标签。
5. 按 ERP 分类查询 SKU，并按资源来源、参考角色、九大风格和联动场景筛选素材。
6. 公共/个人资源按 `visibility` 和上传人真实隔离。
7. 组合项目保存归属 SKU 与参与 SKU 关系，支持按任一参与 SKU 回查。

现状风险：后端当前创建资源时倾向固定为公共资源，查询也未完整按 `visibility` 和上传人隔离。公共素材与我的素材上线前必须修正并验证，否则界面入口与真实权限不一致。

## 8. 状态与异常

- SKU 无本地素材：产品列表仍显示 SKU，并回退 ERP 商品图，进入后显示空状态和上传入口。
- SKU 最近素材不可用：回退 ERP 商品图，再失败则显示空状态。
- 上传失败：保留当前 SKU 上下文并允许重试。
- ERP SKU 停用：历史素材可查看和继续创作，显示停用状态。
- 公共/个人查询失败：保留当前入口，不混合返回另一范围资源。
- 组合参与 SKU 不可用：新建选择器隐藏，历史组合显示需修复或历史状态。

## 9. 验收重点

1. 图片任务已有 SKU 时，资源中心直接显示当前 SKU 素材；已有主体图按现有值高亮，新增参考图入口保持零选择。
2. 点击“切换产品”后，产品素材按 SKU 卡片展示，同一 SPU 下连续排列。
3. 大量产品可按 ERP 分类、名称、SPU 和 SKU 检索；素材可按来源和已有标签筛选。
4. 卡片封面正确使用最近素材并具备 ERP 图片回退。
5. 主体图单选、参考图多选遵循调用参数，确认后返回图片任务。
6. 上传只需选择一个 SKU，资源归集后没有重复产品绑定。
7. 参考图角色可以保存并在再次引用时自动带出。
8. 公共素材和我的素材均有完整列表、分类、标签与搜索状态，查询结果符合真实权限。
9. 组合模式能完成上装、下装和可选鞋履选择，并带回现有图片任务流程。
10. 商品素材库和模特资源库入口、数据与管理流程不受影响。
11. 组合结果只保存一份，参与 SKU 均可查到同一关联组合。

## 10. 明确不做

- 不新增资源与产品多对多关系。
- 不把资源中心改成独立管理页面。
- 不合并或重做商品素材库。
- 不在资源中心增加分类管理、标签管理和 AI 打标流程，只消费 ERP 分类、资源分类与已保存标签。
- 不把模特资源库合并进资源中心。
- 不复制组合结果到多个 SKU。
- 不在本设计阶段修改前后端业务代码、数据库或环境配置。
