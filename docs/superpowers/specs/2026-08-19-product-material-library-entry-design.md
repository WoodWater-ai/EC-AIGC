# 产品素材库入口与合并设计

> 日期：2026-08-19  
> 状态：已确认，进入实施

## 目标

从产品管理的每个 SKU 直接进入其产品素材库；在该二级素材库中复用一级素材库的图片合并抽屉；产品管理的批量上传素材只在产品素材库出现，不再出现在通用素材库。

## 设计

1. `ProductManagePage` 的 SKU 操作区增加素材库入口。入口在当前弹窗生命周期内把目标 SKU 传给 `AssetTransitModal`，并以产品素材、管理模式打开。
2. `AssetTransitModal` 增加可选的初始 SKU 上下文。存在上下文时直接展示该 SKU 的素材，不需要先经过产品列表。
3. 当前 SKU 素材选择至少两张图片时，复用 `ResourceMergeDrawer`。抽屉默认选中“上下合成”，仍保留一级素材库已有的顺序调整、方向切换、预览、命名和上传行为。
4. 合并产物创建后，调用现有 `productLibraryApi.setInputAssetCover(productId, assetId)`，仅更新产品素材封面，不修改 ERP 商品主图。
5. 通用素材分页在未指定 `productId` 时只返回 `product_id IS NULL` 的资源。产品素材库仍通过其现有产品关联查询读取上传和合并产物。

## 错误与兼容性

- 合并上传失败时保持抽屉与预览，允许重试。
- 封面设置失败时向用户显示错误，合并资源仍保留在当前 SKU 的素材库中。
- 不新增表、字段、文件副本或上传流程；已有带 `product_id` 的历史素材会在通用素材查询收紧后自动消失。

## 验收

1. 单 SKU 与多 SKU 行均能打开各自素材库。
2. 二级素材库可以合并两张及以上图片，默认“上下合成”，且可调整顺序和切换方向。
3. 合并成功后产物出现在当前 SKU，并标记为产品素材封面；ERP 主图未变化。
4. 扫描批量上传的产品素材不会在通用素材查询结果中出现。
