# 视频 Prompt 与详情抽屉设计

## 目标

降低任务详情对主列表的遮挡，并让视频任务与图片任务采用相同的提示词心智模型：先编辑一份最终 Prompt，再由系统按视频时长拆成可继续编辑的分镜。

## 交互

- 图片任务详情抽屉的桌面最大宽度收为 980px；小屏仍占满可用宽度。
- 视频内容区默认只展示“本次视频 Prompt”和“生成提示词”动作。该动作生成或刷新按时长划分的分镜提示词。
- 分镜在生成前不出现；生成后显示为可编辑区域。总 Prompt 是唯一必填项，分镜是提交时附带的增强上下文。
- 商品事实位于左侧输入列底部，展示关联商品的品类、颜色、材质与卖点；没有关联商品时明确显示缺失状态。
- 执行确认弹窗不再展示完整 Prompt，仅保留来源素材、参考顺序和模型参数等会影响费用或执行结果的摘要。

## 状态和提交

- `segmentsGenerated` 记录当前时长是否已生成分镜；改变时长或输入素材会清空分镜并要求重新生成，避免旧分镜被误认为适用于新输入。
- 每次生成分镜均从当前总 Prompt 派生全量分镜；用户可在生成后逐镜编辑，重新生成则明确以当前总 Prompt 重建。
- 提交的任务 Prompt 继续包含总 Prompt、输入素材和已生成的分镜，保持任务详情与后续追溯完整。

## 验证

- TypeScript 检查、既有测试和生产构建必须通过。
- 在桌面和窄屏下确认详情抽屉宽度、视频 Prompt 的生成前后状态，以及执行确认摘要不出现完整 Prompt。
