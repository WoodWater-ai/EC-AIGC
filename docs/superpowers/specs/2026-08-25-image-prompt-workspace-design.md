# 图片任务中栏 Prompt 工作区设计

## 目标

将独立的输出类型区与逐类型 Prompt 编辑器合并成一个简洁的中栏工作区，保留多类型任务能力，并让模板复用、创作标签、执行参数和 Prompt 编辑形成同一上下文。

## 信息架构

中栏只保留一个工作区，顺序为：

1. 左上角三个类型 Tab：场景主图、细节图、三视图。
2. 右上角模板按钮，打开右侧模板抽屉。
3. 当前 Tab 对应的“设计师创意”编辑框。
4. 彩色参考图绑定标签。
5. 当前类型可编辑的约束规则。
6. 创作标签：风格、场景、姿势。
7. 执行参数：张数、模型、比例、尺寸及高级设置。

删除独立“输出类型”卡片、内容眉题、副标题、已选类型统计和常驻成功提示。错误、不可执行和参数失效信息属于必要状态，继续保留。

## 类型规则

- 新任务只暴露三个 UI 分类。
- 场景主图使用现有 `scene_detail` 提交类型；旧 `PRODUCT_MAIN` 与 `SCENE_DETAIL` 模板均归入场景主图模板分类。
- 旧 `PRODUCT_MAIN` 模板在新页面应用时转换为 `scene_detail`，不修改后端枚举。
- 细节图继续使用 `detail_closeup`，三视图继续使用 `model_triple_view`。
- Tab 只负责切换编辑上下文，不显示复选框，也不维护独立启用状态。
- 某类型“设计师创意”去除首尾空白后非空时，自动加入本次任务；为空时不提交该类型。
- 动态参考图标签、商品事实和默认约束规则不触发生成。
- 新任务三个类型的设计师创意均为空，模板、助手带入或用户输入后才生成对应类型。
- 三个设计师创意全为空时不允许提交。

## Prompt 与张数

- 页面一次只显示当前 Tab 的设计师创意，编辑框置顶突出，最小高度为 180px，并允许纵向调整。
- 张数不放在 Tab 或 Prompt 标题中，放到执行参数首位；切换 Tab 后显示当前类型张数。
- 当前类型手工编辑后显示撤销图标，点击清空或恢复模板初始化内容。
- 删除“按表单重算”文字按钮及其面向全部类型的显式入口。
- Tab 等宽排列，不出现横向或纵向滚动条；当前 Tab 只通过文字颜色和底部强调线表达。

## 参考图绑定与约束

- 主图固定显示“主图参考 图1”，其余素材按左侧当前顺序从图2开始编号。
- 同一素材承担多个角色时分别显示多个标签，共用同一个图号。
- 角色标签使用浅色背景、同色边框和实色图号块；主图、模特、场景、细节、姿势、风格颜色各自区分。
- 标签只读、自动换行，不出现横向滚动条。
- 约束规则完整展示并允许编辑；提供恢复当前类型默认规则的图标按钮。
- 场景主图默认约束商品保真，细节图默认禁止虚构工艺，三视图默认约束人物、商品、光线和视角一致性。

## 最终 Prompt

提交前由前端组合为五段精简内容：图片类型要求、设计师创意（含创作标签）、参考图绑定、商品事实、约束规则。页面不再直接展示或维护原来的长串完整 Prompt。

## 模板抽屉

- 点击当前 Prompt 右上角模板按钮，从中栏右侧打开抽屉。
- 模板按当前 Tab 分类筛选；场景主图同时接收 `PRODUCT_MAIN` 与 `SCENE_DETAIL`。
- 列表显示模板名、Prompt 摘要、模型、比例和尺寸。
- 选择模板后初始化当前类型的设计师创意、可识别的约束规则、张数、风格、场景、姿势、模型和 schema 参数。
- 新结构模板按段落拆分；旧模板优先提取“用户创意补充”，无法识别的自由 Prompt 原文保留在设计师创意区。
- 模板不会替换左侧主体素材、商品事实或当前参考图，避免中栏操作产生跨区域副作用。
- 模板加载或执行参数不可用时保留当前编辑内容，并展示明确错误。

## 技术边界

- 复用 `creationTemplateApi.camp('IMAGE')` 获取模板，复用 `creationTemplateApi.reuseContext(id)` 获取快照。
- 复用 `ImageSettingsSection` 的 `PrefillState` 初始化模型与 schema 参数。
- 仅调整前端组件、状态映射和文案；不修改服务端、数据库和接口契约。

## 验收

- 中栏不再出现独立输出类型卡片。
- 三个 Tab 可来回切换并分别编辑 Prompt，不显示勾选框或独立启用控件。
- 只有设计师创意非空的类型进入右侧汇总、确认弹窗和提交载荷。
- 默认约束和参考图标签存在时，不会让空类型进入任务。
- 张数只出现在执行参数区。
- 模板抽屉按当前 Tab 筛选，应用后 Prompt 与参数同步更新。
- 约束规则手工修改后可恢复当前分类默认值。
- 页面不出现无关副标题和轻提示，必要错误状态仍可见。
