# 资源中心归属、标签与模特素材设计

**状态：** 已确认，执行 PRD、HTML 效果稿与前端同步  
**日期：** 2026-08-11  
**范围：** V2.5 图片任务内资源中心产品规则、效果稿与前端实现；不涉及后端业务代码、数据库迁移或生产配置

## 1. 目标

资源中心只解决三件事：

1. 按 SKU 查找和归集产品素材。
2. 管理未关联产品的个人或团队通用素材。
3. 查找模特档案，并把人物图片转换为模特素材。

设计继续遵循一条资源只关联一个产品 ID、底层文件不重复存储、ERP 分类为商品分类唯一来源的约束。

## 2. 一级信息架构

资源中心使用三个横向一级 Tab：

```text
[产品素材] [通用素材] [模特素材]                         搜索
```

- `产品素材`：关联唯一 SKU，始终在团队内共享。
- `通用素材`：未关联 SKU，可见范围由系统配置决定。
- `模特素材`：沿用独立模特库的数据和管理规则，只把入口放到资源中心横向 Tab。

图片和视频继续作为筛选条件，不升级为一级 Tab。模特素材只展示图片。

## 3. 通用素材可见范围配置

系统配置增加“通用素材可见范围”：

```text
通用素材可见范围
● 个人（默认）
○ 团队
```

规则：

- 默认值为 `个人`，用户只看到本人未关联产品的通用素材。
- 切换为 `团队` 后，工作空间成员可查看团队范围内的通用素材。
- 配置作用于通用素材库整体查询范围，不为每张素材增加一套独立可见性编辑入口。
- 产品素材不受该开关影响，始终团队共享。
- 从团队切回个人后，通用素材恢复按上传人隔离；已归集的产品素材不受影响。

资源中心只显示当前配置结果，不在资源弹窗内提供修改开关。配置修改属于管理员的系统配置能力。

## 4. 产品素材

### 4.1 列表布局

产品素材统一按 SKU 展示：

- 封面比例为 `9:16`。
- 宽屏每行 5 个，较窄桌面每行 4 个。
- 同一 SPU 的 SKU 必须连续排列。
- 多规格 SPU 显示轻量分组标题和 SKU 数量。
- 单规格商品直接进入 SKU 网格，不为每个单规格 SPU 增加占空间的独立分组标题。
- SKU 卡片展示当前白底图、ERP 商品名称、规格、SKU 编码、素材数量和最近使用时间。
- 当前白底图复用现有规则：ERP 同步图或用户最近一次更换的图片。

### 4.2 一级筛选

产品素材顶部只保留：

```text
[全部] [最近使用]
```

ERP 商品分类、图片/视频类型和搜索继续作为独立筛选，不保留“最近有图片、单规格、多规格”等一级标签。

### 4.3 多选和搭配合成

- 整张 SKU 卡片可勾选，查看素材按钮不触发勾选。
- 选中 1 个 SKU 时可本地上传或目录扫描，上传结果绑定该唯一 SKU。
- 选中 2 个及以上 SKU 时启用搭配合成，单 SKU 上传入口禁用。
- 搭配合成只读取各 SKU 当前白底图，支持上下或左右拼接。
- 合成结果底层文件只存一份，为每个参与 SKU 建立资源引用。

## 5. 通用素材

### 5.1 一级筛选

通用素材顶部只保留：

```text
[全部] [最近使用]
```

默认个人模式不展示“团队成员”筛选或团队成员素材。团队模式启用后，再根据配置结果展示团队素材。

### 5.2 标签筛选

标签来自用户再生图时选择并随生成结果沉淀，资源中心只筛选，不提供第二套标签编辑能力。

```text
[风格 ▾] [场景 ▾] [细节 ▾] [姿势 ▾]
```

- `风格`：下拉树形多选，使用九大正式风格字典及其子标签。
- `场景`：下拉树形多选，使用与风格联动的场景字典及其子标签。
- `姿势`：下拉树形多选，使用姿势字典及其子标签。
- `细节`：当前没有子标签，使用扁平多选列表，不渲染空层级。
- 每个下拉在按钮上显示已选数量；多个维度之间使用 AND，同一维度内多项使用 OR。
- 清空某个维度后恢复该维度“全部”状态。

### 5.3 设为产品素材

通用素材支持单选后执行“设为产品素材”：

1. 打开 ERP 产品库 SKU 选择器。
2. 用户选择一个有效 SKU；一条素材不能同时关联多个 SKU。
3. 确认后为素材写入唯一产品 ID。
4. 素材从通用素材移出，进入对应 SKU 的产品素材集合。
5. 底层文件不复制；素材归集完成后按产品素材规则团队共享。

如果用户在创作任务中直接选择尚未关联产品的通用素材，沿用现有逻辑打开 ERP SKU 选择器。任务已有唯一 SKU 上下文时可预选该 SKU，但仍由用户确认关联。

### 5.4 设为模特

通用图片保留“设为模特”能力：

1. 仅本人拥有、正常状态、尚未进入模特库的图片可操作。
2. 支持沿用线上批量上限和确认弹窗。
3. 转换时不新增性别、年龄、脸部锚点等必填表单。
4. 模特名称默认取素材名称；标签、适用范围和来源原因沿用线上默认值。
5. 转换成功后素材从通用素材移出，只在模特素材中展示。
6. 后续名称、标签和模特档案信息在模特库中维护。

视频不能设为模特。

## 6. 模特素材

`模特素材`作为第三个横向 Tab，但不把模特档案并入普通资源表：

- 复用现有模特库分页、搜索、标签和发布状态。
- 卡片展示模特主图、名称、标签和可用状态。
- 图片任务可从该 Tab 选择已发布模特。
- 创建、编辑、发布和删除仍由独立模特库业务完成。
- 资源中心不新增性别、年龄、脸部锚点或授权声明编辑表单。

这样能缩短创作任务中的选择路径，同时避免通用图片和模特档案多头管理。

## 7. 关键状态与错误处理

- 通用素材转产品时 ERP SKU 已停用：禁止确认并提示重新选择。
- 转换过程中失败：素材保留在通用素材，不产生半完成归属。
- 模特转换失败：素材保留在通用素材，可重新操作。
- 素材已关联产品：不再出现在通用素材，也不能重复执行“设为产品素材”。
- 素材已进入模特库：不再出现在通用素材，也不能重复执行“设为模特”。
- 通用素材团队模式关闭：不删除团队素材，仅按个人范围隐藏。

HTML 效果稿至少覆盖：

1. 产品素材 5 列 SKU 列表。
2. 同 SPU 多 SKU 连续分组与单规格商品紧凑展示。
3. 产品多选和搭配合成启用状态。
4. 通用素材个人模式及四类标签下拉。
5. 通用素材“设为产品素材”后的 ERP SKU 选择器。
6. 通用图片“设为模特”确认状态。
7. 模特素材横向 Tab 列表。
8. 1280×720 和 1440×900 下无文字、按钮和卡片重叠。
